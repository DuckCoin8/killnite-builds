# KILLNITE — сборки для Mac

Здесь лежат только готовые сборки игры (без исходного кода). Каждая сборка — отдельный релиз:
[**все релизы**](../../releases) · [**последняя сборка**](../../releases/latest).

- Нужен Mac на Apple Silicon **M2 или новее** и **macOS 15** или новее.
- Играть можно только с аккаунтом KILLNITE (killnite.com).
- Архив разбит на две части (`.part-aa`, `.part-ab`): у GitHub предел 2 ГБ на файл.
  Как склеить, установить и запустить — в `README` внутри релиза.
